## Using the Assembler

### Requirements
- Python 3.x

### Steps
1. Write your assembly code in `assemblycode.asm`.
2. Open a terminal and navigate to the folder in which you have both the `assembler.py` and `assemblycode.asm`.
3. run : `python assembler.py`

The output will be written to `machinecode.mem`, one instruction per line in binary.
